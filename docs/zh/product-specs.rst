产品技术参数
============

测量范围和精度
--------------

温度测量范围和精度
~~~~~~~~~~~~~~~~~~

.. list-table::
   :stub-columns: 1

   * - 产品
     - WTHM/WCO2/WVOC
     - WENS
   * - 测量范围
     - -25 ~ +65 ℃
     - -40 ~ +85 ℃
   * - 测量误差
     - ±0.4 ℃ (0 ~ 65 ℃ 区间), ±0.8 ℃ (全测量范围)
     - ±0.5 ℃ (-10 ~ 85 ℃ 区间), ±1 ℃ (全测量范围)

相对湿度测量范围和精度
~~~~~~~~~~~~~~~~~~~~~~

- 相对湿度测量范围：0 ~ 100 %RH
- 相对湿度测量误差：±3.5 %RH (10 ~ 90 %RH 区间), ±5 %RH (全测量范围)

二氧化碳（CO₂）测量范围和精度
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- CO₂ 测量范围：400 ppm – 2000 ppm
- CO₂ 测量误差：±(50 ppm + 读数的 5%)

TVOC 测量范围和精度
~~~~~~~~~~~~~~~~~~~

- TVOC 测量范围：0 – 10,000 ppb
- TVOC 测量误差：典型误差 < 测量值的 12%

设备电源
--------

- 支持标准USB Type-C 5V供电。额定工作电流100mA，峰值工作电流小于200mA。
- 支持DC电源端子供电，额定输入电压DC12V，范围DC9~28V。

WLAN 无线通讯
-------------

- 支持 IEEE 802.11 b/g/n 标准 2.4 GHz 频段 Wi-Fi 网络。
- 无线安全：WPA2-Personal (PSK)、WPA3-Personal (SAE)、WPA2-Enterprise、WPA3-Enterprise (802.1X/RADIUS)

TTL 3.3V UART串行配置接口
-------------------------

.. list-table::
   :header-rows: 1

   * - 引脚
     - 功能描述
   * - TXD
     - Transmit pin
   * - RXD
     - Receive pin
   * - GND
     - Signal ground pin

此接口一般只用于工厂调试模式。

设备尺寸
--------

- **主机** 长x宽x高：86 x 86 x 43mm
- **背板支架（金属）** 长x宽：70 x 30mm
- **挂件（塑料）** 长x宽：76 x 56mm
