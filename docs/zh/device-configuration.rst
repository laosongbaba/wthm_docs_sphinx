设备参数配置
============

设备连接到 Wi-Fi 网络后，下一步是配置其运行参数。本章介绍如何使用配置工具设置设备名称、工作模式、云服务绑定等设备相关参数。

1. 配置工具概述
---------------

你可以在以下页面下载我们所有设备的配置工具及软件使用手册：

`https://www.monigear.com/software.html <https://www.monigear.com/software.html>`_

2. 查找设备
-----------

电脑连接到与 MN-WTHM 相同的 Wi-Fi AP 网络后，打开设备配置工具软件，点击 **Find** 即可查找到当前网络中的 MN 设备。如设备与电脑不在同一网段，可点击 **Add** 按钮，通过设备的指定 IP 地址进行连接。选择目标设备后，点击 **Configure** 进入设置菜单。

.. figure:: /_static/images/find_device.png
   :width: 210
   :alt: 查找设备

3. 连接设备
-----------

使用默认密码 "wangkong" 连接设备。

.. figure:: /_static/images/connect_device.png
   :width: 210
   :alt: 连接设备

4. 参数设置
-----------

点击 **Detect** 后，选择其中一种 figure type，再点击 **Read Configure** 读取配置。

.. figure:: /_static/images/read_configure.png
   :width: 210
   :alt: 读取配置

5. 应用并保存配置
-----------------

设置好属性和取值后，点击 **Apply Changes** 应用更改，再点击 **Save and Reboot** 保存并重启设备。

.. figure:: /_static/images/apply_configure.png
   :width: 210
   :alt: 应用配置
