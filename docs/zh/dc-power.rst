电源与供电说明
==============

设备支持两种电源供电方式：

1. 支持标准USB Type-C 5V供电。额定工作电流100mA，峰值工作电流小于200mA。
2. 支持DC电源端子供电，额定输入电压DC12V，范围DC9~28V。

使用DC电源供电
--------------

当使用DC电源供电时，拆开设备底壳与面盖的3个固定螺丝，露出设备主板，在USB座所在的电源小板上可以看到DC电源端子。

按丝印所示极性接入DC电源即可给设备供电。额定输入电压DC12V，范围DC9~28V。
